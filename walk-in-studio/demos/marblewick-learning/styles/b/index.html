How lessons run

Three steps, no surprises

  1. Try one class

    Pick a class from the timetable and come for one lesson. We tell you after it which group fits.

  2. Join a small group

    Up to 8 students (6 for JC), the same tutor every week, a short update to parents each month.

  3. Pay monthly

    Fees at the start of each month by e-wallet or bank transfer. Miss a lesson? Join another class that week.

Questions parents ask

Before you register

How do I register?

Book a trial class on WhatsApp or with the form below. If the class fits, we send a short form and the first month’s fee.

What if my child misses a lesson?

They can join another class of the same level that week, or get the lesson notes.

How do I pay?

e-wallet or bank transfer at the start of each month. No deposit, no registration fee.

Can my child change class later?

Yes, when there is a place in the other class. Ask us on WhatsApp.
